# CS 410 Computer Vision & Deep Learning

All 4 programming assignments from CS 4/510 at Portland State (Summer 2026), combined into one repo. Each folder has its own README, code, write-up, and result images, and the original commit history is kept.

| Folder | What it does | Built with |
| --- | --- | --- |
| [assignment-1-filters-kmeans-sift](assignment-1-filters-kmeans-sift) | Convolution image filters, K-means clustering, and SIFT feature matching, all from scratch | NumPy |
| [assignment-2-optical-flow](assignment-2-optical-flow) | Lucas-Kanade optical flow between pairs of frames, no OpenCV flow functions | NumPy |
| [assignment-3-transfer-learning](assignment-3-transfer-learning) | Cats vs. dogs classifier using a frozen pretrained InceptionResNetV2, comparing the full network vs. a cut-down sub-network | TensorFlow/Keras |
| [assignment-4-autoencoders](assignment-4-autoencoders) | Convolutional autoencoders on Fashion-MNIST: reconstruction, denoising, and latent space visualization vs. PCA | TensorFlow/Keras |
